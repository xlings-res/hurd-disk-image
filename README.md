# hurd-disk-image

Debian GNU/Hurd (hurd-amd64), the pre-installed image with a login on the serial line, as a qcow2 disk for emulator runners

Built by the script named in `PROVENANCE.md` inside the archive (openxlings/xim-pkgindex, `.agents/tools/`). Installed by the xlings package `hurd-disk-image`.
